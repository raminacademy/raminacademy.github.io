درس‌های آموزشی

پس از مطالعه هر درس، دکمه «درس را کامل کردم» را بزن تا پیشرفتت ذخیره شود.

کامپیوتر | درس ۱: آشنایی با ویندوز

ویندوز یک سیستم‌عامل است؛ یعنی نرم‌افزاری که اجرای برنامه‌ها و کار با سخت‌افزار را مدیریت می‌کند.

  • Desktop: صفحه اصلی پس از ورود به ویندوز.
  • Start: محل دسترسی به برنامه‌ها و تنظیمات.
  • Taskbar: نوار ابزار پایین صفحه.
  • Recycle Bin: محل نگهداری موقت فایل‌های حذف‌شده.

تمرین: یک پوشه با نام Academy روی دسکتاپ بساز.

کامپیوتر | درس ۲: فایل و پوشه

فایل، داده‌ای مانند عکس یا سند است. پوشه برای دسته‌بندی فایل‌ها استفاده می‌شود.

  • برای ساخت پوشه جدید از گزینه New Folder استفاده کن.
  • برای تغییر نام، فایل را انتخاب و Rename را بزن.
  • برای کپی و چسباندن می‌توانی از Ctrl+C و Ctrl+V استفاده کنی.

کامپیوتر | درس ۳: قطعات اصلی

CPU: دستورها را پردازش می‌کند. RAM: فضای موقت و سریع برای برنامه‌های در حال اجراست. SSD/HDD: اطلاعات را نگهداری می‌کند. مادربرد: قطعات را به هم متصل می‌کند.

کامپیوتر | درس ۴: اینترنت و مرورگر

مرورگر برنامه‌ای برای بازکردن وب‌سایت‌هاست. هنگام ورود اطلاعات، آدرس سایت را بررسی کن و به هشدارهای امنیتی مرورگر توجه داشته باش.

برنامه‌نویسی | درس ۱: HTML

HTML برای مشخص‌کردن ساختار محتوای صفحه وب استفاده می‌شود.

<!DOCTYPE html>
<html lang="fa">
<head><meta charset="UTF-8"><title>اولین صفحه</title></head>
<body>
  <h1>سلام دنیا</h1>
  <p>این اولین صفحه من است.</p>
</body>
</html>

تگ h1 عنوان اصلی و تگ p یک پاراگراف می‌سازد.

برنامه‌نویسی | درس ۲: CSS

CSS ظاهر عناصر HTML را تعیین می‌کند؛ مثل رنگ، اندازه و فاصله.

h1 {
  color: deepskyblue;
  text-align: center;
}

در این مثال عنوان آبی و وسط‌چین می‌شود.

برنامه‌نویسی | درس ۳: JavaScript

جاوااسکریپت به صفحه وب رفتار و تعامل اضافه می‌کند.

const button = document.querySelector("button");
button.addEventListener("click", function () {
  alert("سلام!");
});

این نمونه با کلیک روی دکمه یک پیام نشان می‌دهد.

برنامه‌نویسی | درس ۴: Python

پایتون زبانی خوانا و پرکاربرد است.

name = "Ramin Academy"
print("Welcome to", name)

تابع print متن را در خروجی نمایش می‌دهد و name یک متغیر است.

امنیت | درس ۱: رمز عبور امن

برای هر حساب، رمز متفاوت و طولانی انتخاب کن. از رمزهای قابل حدس مانند نام یا تاریخ تولد استفاده نکن و رمز را برای دیگران نفرست. در صورت امکان تأیید دومرحله‌ای را فعال کن.

امنیت | درس ۲: شناخت فیشینگ

فیشینگ تلاش برای فریب افراد و گرفتن اطلاعات آن‌هاست. پیام‌های فوری و تهدیدآمیز، جایزه‌های غیرمنتظره و لینک‌های ناشناس را با دقت بررسی کن. قبل از واردکردن رمز، آدرس سایت را خودت بررسی کن.

امنیت | درس ۳: حریم خصوصی

نشانی خانه، شماره تماس، رمزها و اطلاعات خصوصی را در صفحه‌های عمومی منتشر نکن. دسترسی برنامه‌ها به دوربین، میکروفون و موقعیت مکانی را فقط در صورت نیاز بررسی کن.

امنیت | درس ۴: محافظت از دستگاه

سیستم‌عامل و برنامه‌ها را به‌روز نگه دار، قفل صفحه فعال کن و برنامه‌ها را از منابع معتبر دریافت کن. از فایل‌های ناشناس و پیوست‌های مشکوک دوری کن.
